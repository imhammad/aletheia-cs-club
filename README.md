# Aletheia CS Club

Truth, Engineered.

Portfolio landing site for Aletheia CS Club, a CS club community of builders, thinkers, and AI explorers. Built with Next.js, TypeScript, Tailwind CSS, GSAP/ScrollTrigger, and Lenis.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis (smooth scroll)
- Framer Motion

## Getting Started
\`\`\`bash
npm install
npm run dev
\`\`\`
Open http://localhost:3000
